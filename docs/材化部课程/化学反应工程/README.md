# 化学反应工程

> 化学反应工程是材化部的专业选修课（化工专业必修），内容为化工基础后半部分"反应工程"的延伸与深化，涉及理想反应器设计、均相与非均相反应动力学、停留时间分布等。

## 学习建议

### 选课前须知

- 这门课是化学工程与工艺专业的必修课，**不建议**以选修为目的选这门课，难度较高，而且事情巨多。
- 老师强制要求选这门课的同学必须参加化学工程创赛，并以此为打分依据，每周会留作业，总体非常麻烦。
- 这门课与[化工基础](../化工基础)后半段衔接紧密，化工基础中只学了教材一半，本课把剩余的反应工程部分讲完，建议两门课对照复习。

### 核心考点

- 核心是**反应器设计**：理想间歇反应器（BR）、全混流反应器（CSTR）、活塞流反应器（PFR）的体积计算与选型对比是必考重点，务必把三类反应器的公式与适用条件吃透。
- 停留时间分布（RTD）与返混是难点也是常考点，理解 E(t)、F(t) 曲线的物理意义及方差计算。
- 非均相反应（气固催化、气液反应）的速率控制步骤判断与宏观动力学是后半学期重点，注意区分本征动力学与宏观动力学。

### 复习策略

- 复习以**例题与试题**为主：本课收录的三套试题（基础部分、复习题、期末）基本覆盖考查题型，把计算题逐道做熟即可应付考试。
- 总体而言计算量大但套路固定，**掌握反应器体积计算与动力学推导**即可拿较高分数。

!!! warning "选修慎选"
    难度高、任务重，老师强制参加化学工程创赛并以此打分，每周还有作业，不建议以选修为目的选修。
